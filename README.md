# DTM Video Player

Android-Videoplayer (Kotlin, Media3/ExoPlayer).

## APK bauen (GitHub, kostenlos bei öffentlichem Repo)
1. Inhalt dieses Ordners in ein GitHub-Repo hochladen (inkl. Ordner `.github`).
2. Reiter **Actions** → „Build APK" → läuft automatisch (oder „Run workflow").
3. Fertigen Lauf öffnen → unten **Artifacts** → `DTM-Video-Player-APK` herunterladen, entpacken, installieren.
